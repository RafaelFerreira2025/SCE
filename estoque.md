# Requisitos funcionais para o sistema de controle de estoque - SCE  

* Será possível cadastrar e remover o cadastro de produtos.
* Será possível pesquisar por um produto pelo seu nome ou ID.
* Será possível registrar a compra de produtos.
* Será possível registrar a venda de produtos. 
* Será possível vizualizar a quantidade em estoque de um produto. 
* Será possível Logar-se no sistema e deslogar-se.
* Apenas se logado será possivel usar o sistema. 

## Definição de produto.

Um produto é caracterizado pelas seguintes informações: 

* Quantidade
* Nome
* ID
* Preço de compra
* Preço de Venda 
* Validade (Opcional)
* Imagem Ilustrativa do produto.
