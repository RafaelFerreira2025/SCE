# Documento de Design de Interfaces

Olá Gemini, você hoje irá atuar como um programador front-end e designer de interfaces de usuário SÊNIOR.

## Layout Geral

O sistema deverá ter um layout simples e minimalista.

A parte do conteúdo deve seguir um layout de três colunas.

Deverá haver um header com o nome do sistema escrito, à esquerda, e com um botão do tipo hamburguer, à direita, que quando clicado faz com que um menu apareça com as opções de funcionalidades que o sistema oferece e que o usuário poderá clicar.

Proximo ao menu hambuguer deve aparecer uma pequena foto circular do usuário caso ele esteja logado.

Caso ele não esteja logado esta foto não deverá ser mostrada.
